ГОРИЗОНТАЛЬНА ВЕРСІЯ РОЗТАШУВАННЯ (портал / index.html)
=========================================================
Збережено: 2026-09-17

Це знімок порталу (index.html + css/style.css), де блоки "Метаноя 2026"
та "Контури відновлення 2025" розташовані один під одним (рядками),
розділені ГОРИЗОНТАЛЬНОЮ лінією, на будь-якій ширині екрана
(без вертикальної лінії-розділювача по центру).

Щоб повернути цю версію розташування:
- скопіювати css_style.css назад у site/css/style.css
  (або перенести лише правила .gateway-main / .gateway-divider / .gateway-col
  та їх @media (max-width: 860px) блок — решта стилів на момент збереження
  ідентична поточному сайту).
